# NFR-I18N-001 英語と日本語で表示を切り替える

## 要求

利用者が表示言語を選択すると、選択した言語を記憶し、画面に表示する文言を
その言語のメッセージに置き換えて、数値と日付をその言語の書式で整形して表示する。

<!-- 動詞: 選択する / 記憶する / 置き換える / 整形する / 表示する = 5個 -->

## 理由

移植元は11言語に対応しており、日本語は22ファイル・1,347キーが訳されている。
全言語中3番目の充実度であり、**移植先で日本語を落とすと機能後退になる**。

一方、移植元の翻訳支援ツール（`l10n-tool`、99ファイル・30,728行）は
Java 独自の仕組みであり、Web アプリケーションでは next-intl が同等以上を提供する。
ツールは移植せず、**訳文だけを資産として引き継ぐ**判断になる。

英語を含めるのは、移植元が英語を基準言語としており、
未訳のキーが生じたときの表示先が必要なためである。

## 説明

### 移植元との差異

| 項目 | 移植元 | 移植先 | 判断 |
|---|---|---|---|
| 仕組み | `.properties` ＋ `l10n-tool` | **next-intl ＋ JSON** | Web の標準的な方法を採る |
| 対応言語 | 11言語 | **英語・日本語の2言語** | 第1期の範囲。他言語は第2期以降 |
| 翻訳支援ツール | `l10n-tool`（30,728行） | **移植しない** | next-intl が代替する |
| 言語の判定 | 実行環境のロケール | **利用者の明示的な選択** | 意図しない切り替わりを避ける |

### 既存の訳文の扱い

移植元の日本語訳1,347キーは**用語の統一に用いる**。

⚠️ ただし本体 UI の網羅率は 20.1% であり、大半は新規に訳すことになる。
既存訳の価値は「網羅」ではなく「**PSP 用語の訳し方を揃える**」ことにある。

例として、`yield` を「歩留まり」と訳すか「除去率」と訳すかは、
既存訳に従うことで移植元の利用者にとって違和感がなくなる。

### メッセージの構成

```
i18n/messages/
├─ en.json
└─ ja.json
```

キーは画面ごとの階層とする。

```json
{
  "timer": {
    "start": "計測開始",
    "elapsed": "経過時間 {minutes} 分"
  }
}
```

### 言語による書式の違い

| 項目 | 英語 | 日本語 |
|---|---|---|
| 数値 | `1,234.5` | `1,234.5` |
| 日付 | `Aug 10, 2026` | `2026年8月10日` |
| 複数形 | `1 defect` / `2 defects` | 変化しない |

**複数形の扱いが要る。** 欠陥数や時間の表示で英語は語形が変わる。

### データの範囲

| 項目 | 範囲 |
|---|---|
| 対応言語 | `en` / `ja` の2つ |
| 未定義キーの扱い | 英語にフォールバックする |
| 言語設定の保持 | 利用者ごとに1つ |

## 仕様

### <表示言語の選択>

- [ ] **NFR-I18N-001.10** 英語と日本語のいずれかを選択できるようにする。
- [ ] **NFR-I18N-001.20** 初回の起動時は、実行環境のロケールが日本語であれば日本語を、それ以外は英語を初期値とする。
- [ ] **NFR-I18N-001.30** 言語を切り替えた時点で、表示中の画面に反映する。

### <選択の記憶>

- [ ] **NFR-I18N-001.110** 選択した言語を保存し、次回の起動時に復元する。
- [ ] **NFR-I18N-001.120** 保存された言語が `en` と `ja` のいずれでもない場合、英語として扱う。

### <文言の置き換え>

- [ ] **NFR-I18N-001.210** 画面に表示する文言を、すべてメッセージキーを介して取得する。
- [ ] **NFR-I18N-001.220** 選択中の言語にキーが存在しない場合、英語のメッセージを表示する。
- [ ] **NFR-I18N-001.230** 英語にもキーが存在しない場合、キー名をそのまま表示する。
- [ ] **NFR-I18N-001.240** 英語で数量によって語形が変わる文言は、単数と複数を区別して表示する。

### <数値と日付の整形>

- [ ] **NFR-I18N-001.310** 時間を「時間と分」の形式で、選択中の言語の書式で表示する。
- [ ] **NFR-I18N-001.320** 日付を選択中の言語の書式で表示する。
- [ ] **NFR-I18N-001.330** 小数を含む数値を、小数点以下1桁で表示する。

### <文言の管理>

- [ ] **NFR-I18N-001.410** 英語と日本語のメッセージファイルで、キーの集合が一致することを検証する手段を設ける。
